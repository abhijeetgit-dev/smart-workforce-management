# 🚀 Smart Workforce Management System

## 📌 Project Description
Developed a RESTful web application using Spring Boot to manage employee data with CRUD operations and search functionality.

## 🛠 Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- REST API

## ✨ Features
- Add Employee
- Update Employee
- Delete Employee
- View All Employees
- Search Employee by Name
- Validation using Jakarta Validation
- Exception Handling

## ▶️ How to Run
1. Clone the repository
2. Open in IntelliJ
3. Configure MySQL in application.properties
4. Run WorkforceApplication

## 📡 API Endpoints
- GET /employees
- POST /employees
- PUT /employees/{id}
- DELETE /employees/{id}
- GET /employees/search/{name}
